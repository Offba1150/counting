# บอทนับคะแนนเกมทายคำถามในกลุ่มไลน์

บอทนี้จะเข้าไปนั่งอยู่ในกลุ่มไลน์ (กลุ่มปกติ ไม่ใช่ OpenChat) ฟังคำตอบของสมาชิกที่พิมพ์ A/B/C/D
แล้วรอให้แอดมิน (คนที่ดูรูปเฉลยจากเกม) พิมพ์บอกเฉลยเข้ามา จากนั้นจะตัดสินให้คะแนนอัตโนมัติ
และมีคำสั่ง `/export` ให้สร้างไฟล์ Excel สรุปคะแนน พร้อมลิงก์ดาวน์โหลดส่งกลับมาในแชททันที

> ⚠️ **ทำไมแอดมินต้องพิมพ์เฉลยเอง**: เกมที่เล่นอยู่ประกาศเฉลยเป็น "รูปภาพ" ไม่ใช่ข้อความ
> บอทอ่านตัวอักษรจากรูปภาพแบบเชื่อถือได้ยาก (ต้องใช้ OCR ซึ่งมีโอกาสอ่านผิด) จึงออกแบบให้แอดมิน
> ดูรูปแล้วพิมพ์คำสั่งสั้นๆ อย่าง `/ans D` แทน — เร็วกว่าและแม่นยำ 100%

---

## ภาพรวมการทำงาน

1. แอดมินพิมพ์ `/newgame` เพื่อเริ่มเกม (รีเซ็ตคะแนน เริ่มข้อ 1)
2. เกมโพสต์คำถาม ผู้เล่นพิมพ์ตัวอักษรคำตอบของตัวเอง เช่น `D` (นับคำตอบแรกของแต่ละคนต่อข้อเท่านั้น)
3. เกมประกาศเฉลยเป็นรูปภาพ → แอดมินอ่านแล้วพิมพ์ เช่น `/ans D`
4. บอทตรวจคำตอบทุกคนอัตโนมัติ ให้คะแนนคนตอบถูก แล้วเลื่อนไปข้อถัดไปให้เอง พร้อมสรุปในแชทว่าตอบถูกกี่คน
5. ทำซ้ำข้อ 2-4 จนครบทุกข้อ แล้วพิมพ์ `/endgame` เพื่อสรุปคะแนนรวม
6. พิมพ์ `/export` เมื่อไหร่ก็ได้ เพื่อให้บอทสร้างไฟล์ Excel สรุปคะแนน แล้วส่งลิงก์ดาวน์โหลดกลับมาในแชท

คำสั่งทั้งหมด พิมพ์ `/help` ในกลุ่มเพื่อดูได้ตลอด

## ขั้นตอนที่ 1: สร้างบอทไลน์ (LINE Messaging API)

1. เข้า https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชีไลน์ปกติ
2. สร้าง **Provider** ใหม่ (ตั้งชื่ออะไรก็ได้ เช่น "UICC")
3. ในโพรไวเดอร์นั้น กด **Create a new channel** → เลือก **Messaging API**
4. กรอกข้อมูลช่อง (ชื่อบอท, หมวดหมู่, คำอธิบาย) แล้วสร้าง
5. เข้าไปที่แชนแนลที่สร้าง แล้วไปแท็บ **Messaging API**:
   - เลื่อนลงไปกด **Issue** ที่ช่อง *Channel access token (long-lived)* → คัดลอกค่านี้ไว้ (`CHANNEL_ACCESS_TOKEN`)
   - ที่แท็บ **Basic settings** จะมี **Channel secret** → คัดลอกไว้ (`CHANNEL_SECRET`)
6. ในแท็บ **Messaging API** เลื่อนหา:
   - **Allow bot to join group chats** → เปิดเป็น **Enabled** (จำเป็นมาก ไม่งั้นเชิญเข้ากลุ่มไม่ได้)
   - **Auto-reply messages** และ **Greeting messages** → ปิด (Disabled) เพื่อไม่ให้บอทไปทักคนอื่นเอง
7. จำ **Basic ID** ของบอท (หน้าตาแบบ `@xxxxxxx`) ไว้ใช้แอดเป็นเพื่อนทีหลัง

## ขั้นตอนที่ 2: เดพลอยโค้ดขึ้นเซิร์ฟเวอร์ (ใช้ Render.com แบบฟรี)

โฟลเดอร์นี้เป็นโปรเจกต์ Node.js พร้อมใช้งาน ไม่ต้องแก้โค้ดอะไรเลย ทำตามนี้:

1. สร้างบัญชี GitHub (ถ้ายังไม่มี) แล้วสร้าง repository ใหม่ อัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมดขึ้นไป
   - วิธีง่ายสุด: เข้า https://github.com/new ตั้งชื่อ repo แล้วใช้ปุ่ม "uploading an existing file" ลากไฟล์ทั้งโฟลเดอร์ขึ้นไปได้เลย (ยกเว้นโฟลเดอร์ `node_modules` ถ้ามี — ในชุดนี้ยังไม่มีอยู่แล้ว)
2. สร้างบัญชีที่ https://render.com (สมัครฟรีได้ ไม่ต้องผูกบัตร)
3. กด **New +** → **Web Service** → เชื่อมต่อ GitHub แล้วเลือก repo ที่อัปโหลดไว้
4. ตั้งค่า:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. ไปที่แท็บ **Environment** เพิ่มตัวแปรเหล่านี้ (ตามที่คัดลอกไว้จากขั้นตอนที่ 1):
   - `CHANNEL_ACCESS_TOKEN` = (ค่าที่ได้จาก LINE)
   - `CHANNEL_SECRET` = (ค่าที่ได้จาก LINE)
   - `ADMIN_PASSCODE` = ตั้งรหัสผ่านเองสักคำหนึ่ง (เอาไว้ให้แอดมินพิมพ์ยืนยันตัวตนในกลุ่ม)
6. กด **Deploy**. รอสักครู่จนสถานะเป็น "Live" จะได้ URL ประมาณ `https://your-app-name.onrender.com`
7. กลับไปที่แท็บ **Environment** อีกครั้ง เพิ่มตัวแปรอีกหนึ่งตัว (ต้องรอให้รู้ URL จริงจากข้อ 6 ก่อน):
   - `PUBLIC_BASE_URL` = `https://your-app-name.onrender.com` (URL จริงของแอพคุณ **ไม่ต้อง** มี `/webhook` ต่อท้าย)
   - ตัวนี้ใช้สร้างลิงก์ดาวน์โหลดไฟล์ Excel ตอนพิมพ์ `/export` — ถ้าไม่ตั้ง บอทจะสร้างไฟล์ให้แต่ส่งลิงก์ไม่ได้
   - บันทึกแล้ว Render จะ deploy ใหม่อัตโนมัติ

## ขั้นตอนที่ 3: ผูก Webhook เข้ากับบอท

1. กลับไปที่ LINE Developers Console → แชนแนลของคุณ → แท็บ **Messaging API**
2. ที่ช่อง **Webhook URL** ใส่: `https://your-app-name.onrender.com/webhook`
3. กด **Verify** ต้องเห็นเครื่องหมายถูก (สำเร็จ) — ถ้าไม่ผ่าน ให้เช็คว่า Render ขึ้นสถานะ Live แล้วหรือยัง แล้วลองใหม่
4. เปิดสวิตช์ **Use webhook** เป็น Enabled

---

## ขั้นตอนที่ 4: เชิญบอทเข้ากลุ่ม

1. เปิดแอปไลน์ ค้นหา Basic ID ของบอท (`@xxxxxxx`) แล้วแอดเป็นเพื่อน
2. เข้ากลุ่มไลน์ที่เล่นเกม → เพิ่มสมาชิก → เชิญบอทเข้ากลุ่มเหมือนเชิญเพื่อนคนหนึ่ง
3. ในกลุ่ม ให้คนที่จะเป็นแอดมิน (เช่นตัวคุณ) พิมพ์: `/admin <ADMIN_PASSCODE ที่ตั้งไว้>`
   บอทจะตอบว่าตั้งเป็นแอดมินเรียบร้อย ถ้าอยากให้คนอื่นเป็นแอดมินด้วยก็แจ้งรหัสให้เขาพิมพ์เองได้

## เล่นเกมจริง

- `/newgame` — เริ่มรอบใหม่ รีเซ็ตคะแนนทุกคน เริ่มที่ข้อ 1
- ผู้เล่นพิมพ์คำตอบตัวเดียว เช่น `A` `B` `C` `D` (พิมพ์ซ้ำ/เปลี่ยนคำตอบจะไม่ถูกนับ นับแค่ครั้งแรก)
- แอดมินดูเฉลยจากรูปที่เกมส่ง แล้วพิมพ์ `/ans D` (สลับตัวอักษรตามเฉลยจริง) — บอทให้คะแนนคนตอบถูกทันที แล้วเด้งไปข้อถัดไปให้เอง
- `/score` — ดูตารางคะแนนในแชทได้ทุกเมื่อ
- `/skip` — ถ้าข้อนั้นมีปัญหา ข้ามได้โดยไม่มีใครได้คะแนน
- `/endgame` — จบเกม สรุปคะแนนรวม
- `/export` — สร้างไฟล์ Excel (.xlsx) สรุปอันดับ/คะแนน/จำนวนข้อที่ตอบถูก แล้วส่งลิงก์ดาวน์โหลดกลับมาในแชททันที (ต้องตั้งค่า `PUBLIC_BASE_URL` ไว้ก่อน ดูขั้นตอนที่ 2)

## ฟีเจอร์เสริม: ดูดวงรายวัน และถามคำถามทั่วไป

- `/ดวง` หรือ `/ดูดวง` — เปิดไพ่ทาโร่จริง (Rider-Waite) ดูดวงประจำวัน ใช้ได้ทุกคนทุกกลุ่ม เปิดได้วันละ 1 ครั้งต่อคน ไม่ต้องตั้งค่าอะไรเพิ่ม
- **แท็กชื่อบอทในแชทแล้วพิมพ์คำถามต่อท้าย** — บอทจะตอบคำถามทั่วไปให้ (แปลภาษา สรุปเรื่อง ถามความรู้ทั่วไป ฯลฯ) ฟีเจอร์นี้ต้องตั้งค่าเพิ่มก่อนถึงจะใช้ได้ เพราะต้องเชื่อมกับ AI ภายนอก (Gemini API ของ Google):
  1. เข้า https://aistudio.google.com/apikey (ล็อกอินด้วย Google ปกติ ไม่ต้องผูกบัตรเครดิต มี free tier ให้ใช้ฟรี)
  2. กด **Create API key** คัดลอกค่าที่ได้มา
  3. ไปตั้งเป็น Environment Variable ชื่อ `GEMINI_API_KEY` ใน Railway (หน้า Variables ของโปรเจกต์)
  4. รอ deploy เสร็จ แล้วลองแท็กชื่อบอทถามอะไรก็ได้ในกลุ่ม เช่น "@ชื่อบอท วันนี้วันอะไร"
  - ถ้าไม่ตั้งค่า `GEMINI_API_KEY` ไว้ ฟีเจอร์นี้จะปิดอยู่เฉยๆ (บอทจะแจ้งเตือนสั้นๆ เมื่อมีคนแท็กถาม) ฟีเจอร์อื่นทั้งหมดในบอทยังใช้งานได้ตามปกติ
  - free tier ของ Gemini มีโควต้าจำกัดต่อวัน เพียงพอสำหรับกลุ่มไลน์เล็กๆ ถ้าใช้เยอะจนโควต้าเต็ม บอทจะแจ้งว่าตอบไม่ได้ชั่วคราว ลองใหม่ภายหลังได้

## ฟีเจอร์เสริม: เกมเลี้ยงสัตว์เลี้ยง (Tamagotchi) 🐾

แต่ละคนรับเลี้ยงสัตว์เลี้ยงของตัวเองได้ 1 ตัว สะสม **"พลังชีวิต"** (แต้มสะสม ไม่มีเพดาน) เพื่อให้สัตว์เลี้ยงโตขึ้น
เป็นขั้นๆ ถ้าขาดดูแลติดต่อกันจะป่วย แต่ **ไม่มีตายถาวร** — ป้อนยาแล้วหายได้เสมอ ใช้ได้ทุกคนทุกกลุ่ม ไม่ต้องตั้งค่า
อะไรเพิ่ม

**คำสั่งดูแลพื้นฐาน:**
- `/รับเลี้ยง <ชื่อ>` (หรือ `/เลี้ยงสัตว์ <ชื่อ>`) — รับเลี้ยงสัตว์เลี้ยงของตัวเอง (คนละ 1 ตัว บอทสุ่มสายพันธุ์ให้)
- `/ให้อาหาร` (หรือ `/ป้อนข้าว`, `/ป้อนอาหาร`) — ดูแลสัตว์เลี้ยง **รอบละ +25 คะแนนพลังชีวิตทันที** ใช้ได้แค่ 2 ช่วง
  ตามเวลาไทยจริง: **ช่วงเช้า 06:00-12:00 น.** และ **ช่วงบ่าย 12:01-18:00 น.** (นอกสองช่วงนี้ป้อนอาหารไม่ได้)
- `/ป้อนยา` — รักษาตอนป่วย หายป่วยทันที (ไม่ได้คะแนนเพิ่ม แต่หยุดการเสียคะแนนจากความป่วยได้)
- `/สัตว์เลี้ยง` (หรือ `/เพ็ท`, `/pet`) — ดูสถานะสัตว์เลี้ยงของตัวเอง (พลังชีวิตสะสม + ระยะการเติบโต)
- `/สัตว์เลี้ยงกลุ่ม` (หรือ `/เพ็ทกลุ่ม`) — ดูสัตว์เลี้ยงของทุกคนในกลุ่มพร้อมกัน

**กติกาพลังชีวิตรายวัน:** กด `/ให้อาหาร` แต่ละรอบ (เช้าหรือบ่าย) ได้ **+25 คะแนนทันที** ดูแลครบทั้งเช้า+บ่ายใน 1 วัน
= +50 คะแนน ดูแลครึ่งวัน (แค่เช้าหรือแค่บ่ายอย่างใดอย่างหนึ่ง) ก็ยังได้ +25 เฉยๆ **ไม่มีโทษเพิ่ม** แต่ถ้า
**ขาดดูแลไปเลยทั้งวัน** (ไม่ป้อนอาหารแม้แต่รอบเดียว) จะโดนหักพลังชีวิต **-20 คะแนน** ตอนสิ้นวัน (พื้นต่ำสุดคือ 0 ไม่ติดลบ)
และถ้าขาดดูแลทั้งวันติดต่อกัน 2 วันขึ้นไปจะ **ป่วยทันที**

**ระยะการเติบโต** (อิงจากพลังชีวิตสะสม โตแล้วไม่มีวันถอยกลับแม้แต้มจะลดลงภายหลังจากถูกปล่อยละเลย):
ไข่ลึกลับ → ลูก (Baby, 50 คะแนน) → เด็ก (Child, 400 คะแนน) → วัยรุ่น (Teen, 1,000 คะแนน) →
โตเต็มวัย (Adult, 2,000 คะแนน) → พร้อมสืบพันธุ์ (Breeding, 4,000 คะแนน) → แก่จัด (Old, 7,500 คะแนน) →
ตำนาน (Legend, 15,000 คะแนน)

**🎲 เหตุการณ์พิเศษ (สุ่มวันละ 4 รอบ)** — เกม **"พิมพ์ตามให้ตรงเป๊ะ"** เปิดให้ทุกคนในกลุ่มแข่งกัน:

บอทจะ push ข้อความสั้นๆ น่ารักๆ แบบสุ่มเข้ากลุ่มวันละ 4 รอบ (เวลาสุ่มระหว่าง 08:30-17:00 น. แบ่งเป็น 4 ช่วงๆ ละ
~2 ชั่วโมง เพื่อให้กระจายทั้งวัน) สุ่มจากคลังกว่า 50 ข้อความ (โทนหิว/อยากเดินเล่น/อยากให้อุ้ม/ไม่สบาย) เช่น
"หิวจัง ขอเพิ่มอีกคำ" — **ใครในกลุ่มพิมพ์ข้อความนั้นตามให้ตรงเป๊ะได้** ภายใน **1 นาที** (ต้องมีสัตว์เลี้ยงของตัวเอง
อยู่แล้วถึงจะรับรางวัลได้ ถ้ายังไม่มีจะพิมพ์ถูกแต่ไม่ได้อะไร รอบไม่ปิด คนอื่นแข่งต่อได้) เปิดให้มีผู้ชนะได้หลายคน
ในรอบเดียว: **5 คนแรก** ที่พิมพ์ถูกได้ **+30 คะแนน** คนละครั้ง คนที่เหลือ (ยังทันภายใน 1 นาที) ได้ **+10 คะแนน**
คนละครั้ง พอครบ 1 นาทีบอทจะ push แจ้งหมดเวลา พิมพ์ถูกหลังจากนั้นจะไม่ได้คะแนนแล้ว

**โควต้า**: เหตุการณ์พิเศษ 4 ครั้ง/วัน + ข้อความแจ้งหมดเวลาอีก 4 ครั้ง/วัน รวมประมาณ 240 ข้อความ push/เดือน
ยังต่ำกว่าโควต้าฟรีของ LINE OA (300 ข้อความ/เดือน) แต่เหลือพื้นที่ไม่มากแล้ว ถ้าจะเพิ่มฟีเจอร์ push อื่นในอนาคต
ควรพิจารณาโควต้านี้ด้วย

## ข้อควรรู้เกี่ยวกับ Render แบบฟรี (สำคัญ)

- แผนฟรีของ Render จะ **หลับ (sleep)** เมื่อไม่มีคนเรียกใช้นานเกิน ~15 นาที พอมีข้อความแรกเข้ามาจะต้อง "ปลุก" เซิร์ฟเวอร์ ซึ่งอาจใช้เวลา 30-50 วินาที ทำให้บอทดูเหมือนไม่ตอบสนองในข้อความแรก
  - ใช้บริการปิงฟรี เช่น https://uptimerobot.com หรือ https://cron-job.org ตั้งให้ปิง `https://your-app-name.onrender.com/api/scores` ทุก 5 นาที เพื่อไม่ให้หลับ
  - ถ้าเล่นบ่อยและอยากให้เสถียร 100% ไม่มีอาการหลับเลย พิจารณาอัปเกรดเป็นแผน Starter ของ Render (ประมาณ $7/เดือน) หรือย้ายไปโฮสต์อื่น (ดูหัวข้อถัดไป)
- **ถ้าเจออาการ Webhook ขึ้น 404 ตลอด ทั้งที่ตั้งค่าถูกทุกอย่างแล้ว**: บางครั้ง Render (โดยเฉพาะแผนฟรี) มีปัญหา edge network ที่ทำให้คำขอจากบางภูมิภาค/IP ของบริการภายนอก (เช่นเซิร์ฟเวอร์ของ LINE เอง หรือบริการ uptime monitor) ได้รับ 404 ทั้งที่เปิดจากเบราว์เซอร์ปกติใช้งานได้ดี — ลองสั่ง **Manual Deploy → Clear build cache & deploy** ก่อน ถ้ายังไม่หาย แนะนำย้ายไป deploy ที่ **Railway.app** แทน (ฟรีเช่นกัน โค้ดชุดเดียวกันนี้ใช้ได้เลยไม่ต้องแก้ไข แค่เปลี่ยนขั้นตอนที่ 2 เป็น deploy ที่ Railway แทน Render)
- **คะแนนและไฟล์ Excel เก็บในดิสก์ของเซิร์ฟเวอร์**: แผนฟรีของ Render มีดิสก์ที่ไม่ถาวร (ephemeral) ถ้ามีการ deploy ใหม่หรือรีสตาร์ทเซิร์ฟเวอร์ ไฟล์ในเครื่องจะถูกล้าง
  - **ไฟล์คะแนน/สัตว์เลี้ยง (`data/scores.json`)** — ป้องกันได้แล้ว! ถ้าตั้งค่า `GITHUB_GIST_TOKEN` ไว้ (ดูวิธีตั้งค่าในไฟล์ `.env.example` หรือหัวข้อ "สำรองข้อมูลอัตโนมัติกันคะแนนหาย" ด้านล่าง) บอทจะสำรองขึ้น GitHub Gist ส่วนตัวอัตโนมัติทุก ~30 วินาทีที่มีการเปลี่ยนแปลง แล้วดึงกลับมาคืนเองตอนเริ่มทำงานใหม่หลัง deploy หรือรีสตาร์ท — เช็คสถานะได้โดยพิมพ์ `/backup` ในกลุ่ม
  - **ไฟล์ Excel ที่สร้างจาก `/export`** (โฟลเดอร์ `exports/`) — ยังไม่ได้สำรองอัตโนมัติ ยังคงต้องพิมพ์ `/export` แล้ว**ดาวน์โหลดไฟล์เก็บไว้ทันที**หลังเล่นจบแต่ละเกม อย่าปล่อยไว้นาน (ไฟล์นี้สร้างขึ้นใหม่ได้จากคะแนนที่สำรองไว้อยู่แล้ว จึงยังไม่จำเป็นต้องสำรองซ้ำ)

### สำรองข้อมูลอัตโนมัติกันคะแนนหาย (GitHub Gist)

แนะนำให้ตั้งค่านี้เสมอถ้าใช้ Render แผนฟรี (หรือโฮสต์ฟรีอื่นที่ดิสก์ไม่ถาวร) วิธีตั้งค่า:

1. เข้า https://github.com/settings/tokens (ล็อกอินด้วยบัญชี GitHub เดียวกับที่ใช้อัปโหลดโค้ดบอทนี้ในขั้นตอนที่ 2)
2. กด **Generate new token** → **Generate new token (classic)**
3. ตั้งชื่ออะไรก็ได้ (เช่น `line-quiz-bot backup`), **Expiration** เลือก **No expiration** (หรืออายุยาวๆ ก็ได้)
4. ติ๊กเลือกสโคป **gist** อย่างเดียว (ไม่ต้องติ๊กอย่างอื่น) แล้วกด **Generate token**
5. คัดลอกค่าที่ได้ (ขึ้นต้นด้วย `ghp_...`) — เห็นได้ครั้งเดียวตอนสร้าง ถ้าพลาดต้องสร้างใหม่
6. ไปที่ Render → แท็บ **Environment** → เพิ่มตัวแปร `GITHUB_GIST_TOKEN` = ค่าที่คัดลอกมา แล้วบันทึก (Render จะ deploy ใหม่ให้อัตโนมัติ)
7. รอสักครู่แล้วพิมพ์ `/backup` ในกลุ่มไลน์ เพื่อเช็คว่าเชื่อมต่อสำเร็จ

จากนั้นบอทจะสร้าง Gist ส่วนตัว (มองไม่เห็นจากคนนอก) ไว้เก็บสำเนาข้อมูลให้เองอัตโนมัติ ไม่ต้องทำอะไรเพิ่ม ถ้าไม่ตั้งค่าตัวนี้ บอทยังใช้งานได้ปกติทุกอย่าง แค่ข้อมูลจะหายถ้ามีการ deploy ใหม่หรือรีสตาร์ทเหมือนเดิม

## ข้อจำกัดที่ควรรู้

- ใช้ได้เฉพาะ **กลุ่มไลน์ปกติ** เท่านั้น (LINE OpenChat ไม่รองรับการเชิญบอท Official Account ตามข้อกำหนดของ LINE)
- บอทอ่านเฉลยจากรูปภาพไม่ได้ ต้องให้แอดมินพิมพ์บอกเอง (`/ans X`)
- นับคำตอบแรกของผู้เล่นต่อข้อเท่านั้น ถ้าผู้เล่นพิมพ์ตัวอักษรอื่นแทรกในแชทโดยไม่ได้ตั้งใจตอบ (เช่นคุยเล่น) อาจถูกนับเป็นคำตอบไปด้วย — ถ้าอยากให้เข้มขึ้น (เช่นต้องพิมพ์ `ตอบ D` เท่านั้น) แจ้งมาปรับ regex ในโค้ดให้ได้

## รันทดสอบในเครื่องตัวเอง (ถ้าอยากลองก่อน deploy)

```bash
npm install
cp .env.example .env   # แล้วกรอกค่าจริงในไฟล์ .env
npm start
```

จากนั้นใช้เครื่องมืออย่าง [ngrok](https://ngrok.com) เปิด tunnel ชั่วคราวมาที่พอร์ต 3000 เพื่อได้ URL แบบ HTTPS ไปตั้งเป็น Webhook URL ทดสอบได้ก่อนค่อย deploy จริง
